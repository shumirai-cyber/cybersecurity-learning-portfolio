# Windows 11 Security Fundamentals

## Project Overview

This beginner project explores built-in Windows 11 security features and basic computer protection.

## Activity 1: Virus and Threat Protection

**Operating system:** Windows 11

**Area checked:** Windows Security — Virus & threat protection

**Observed status:** "No action needed."

### What I learned

Microsoft Defender Antivirus is a built-in Windows security feature that helps protect devices against malware and other threats.

Checking Windows Security is a useful basic troubleshooting step because it helps users identify whether Windows reports any security actions that need attention.

### Result

I opened Windows Security and checked the Virus & threat protection section. The status displayed was "No action needed."

This records what Windows reported at the time of my check. It does not replace a full security assessment.

## Activity 2: Firewall and Network Protection

**Area checked:** Windows Security — Firewall & network protection

**Active network profile:** Public network

**Firewall status:** On

### What I learned

Microsoft Defender Firewall helps monitor network traffic and blocks connections that do not meet its rules. Windows provides different network profiles, including Public and Private, to apply appropriate network settings.

### Result

I checked the active network profile in Windows Security. My laptop showed Public network as the active profile, and the firewall status was On.

### Security observation

Windows may use a Public network profile for a home Wi-Fi connection. This does not necessarily mean the Wi-Fi is a public hotspot. I will review the network classification and keep the firewall enabled.
